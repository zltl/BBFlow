# 安压宝小程序功能需求清单

> 文档状态已与当前代码对齐（2026-08）。以 README 与实现为准；本文件保留需求描述并标注实现状态。

## 一、整体说明

- 产品名称：安压宝（高血压人群血压管理工具）
- 形态：微信小程序
- 类目建议：工具 > 健康管理
- 定位：仅做健康数据记录与展示，不提供诊断和治疗结论

---

## 二、V1.0 核心功能需求（MVP）

### 1. 用户基础
- 使用微信登录（获取 openid 作为用户唯一标识）。（状态：**已实现** — `wx.login` + JWT）
- 首次使用时展示简单引导页/免责声明。（状态：**已实现**）

### 2. 血压记录 - 手动录入
- 字段：收缩压、舒张压、心率、测量时间、标签、备注。
- 校验与保存后跳转趋势页。（状态：**已实现** — 云端 PostgreSQL）

### 3. 血压记录 - 拍照识别（OCR）
- 拍照 → 上传 OSS → 百度 OCR → 置信度校验 → 用户确认后保存。（状态：**已实现**）

### 4. 云端数据存储
- 后端 PostgreSQL 存储血压记录、用药、分享等。（状态：**已实现**）
- 本地 `bp_records` 仅为历史兼容回退，新写入走云端。

### 5. 历史记录列表
- 趋势页内嵌历史 + 独立历史页（「全部」入口）。（状态：**已实现**）

### 6. 血压趋势图
- 小程序 Canvas 折线图 + 健康洞察（7/30/90 天）。（状态：**已实现**）

### 7. 分享数据
- 分享图片、可过期/可撤销分享链接、访问审计、JSON/CSV 导出。（状态：**已实现**）

## 三、V2.0 功能需求（智能增强）

### 1. 拍照 OCR 识别（完善版）
- 置信度、策略、校验与人工修正。（状态：**已实现**）
- 自动裁剪/倾斜矫正等进阶能力。（状态：部分 / 依赖 OCR 服务）

### 2. 用药记录与提醒
- 用药计划 CRUD、打卡、依从性统计。（状态：**已实现**）
- 订阅消息提醒与服务端调度。（状态：**进行中 / 本轮改造**）

### 3. 周报 / 月报自动生成
- 规则引擎洞察与趋势摘要。（状态：**部分实现**）
- 独立周报/月报图片导出。（状态：未完整实现）

### 4. 分享 H5 报告
- Token 链接、过期与撤销。（状态：**已实现**）
- H5 交互图表与摘要增强。（状态：**进行中 / 本轮改造**）

### 5. 会员与支付
- 套餐、订单、订阅状态展示。（状态：**已实现**）
- 微信支付统一下单 + 回调验签。（状态：**进行中 / 本轮改造**）

### 6. 报告文件导出
- JSON/CSV 与账号删除。（状态：**已实现**）
- PDF 报告。（状态：未实现，预留）
