# 高血压健康管理软件项目计划书

---

### **项目名称（建议）：** “心安血压”

本项目按个人开发者可执行的节奏与范围进行规划，优先保证核心价值（血压记录 + 数据分享），其余功能按版本逐步迭代实现。

### **第一部分：产品设计方案**

#### 1. 目标用户

*   **主要用户：** 35岁及以上的高血压患者。他们需要简单、易用的界面来记录和追踪自己的健康状况。
*   **次要用户：** 患者的家人（如子女），他们可能帮助年长的父母记录和管理数据。
*   **关联用户：** 医生或健康管理师，他们需要快速、清晰地查看患者数据以提供专业建议。

#### 2. 核心功能模块

1.  **健康数据记录 (核心)**
    *   **血压记录：**
        *   手动输入高压（收缩压）、低压（舒张压）、心率。
        *   **拍照识别（OCR）：** 允许用户拍摄血压计屏幕，App通过OCR自动读取并填入高压/低压/心率；提供自动裁剪与倾斜校正、眩光/模糊提示与重拍、数值范围校验（如80–200mmHg）、一键确认与手动修正回退，保证易用与准确性。
        *   自动记录测量时间（可修改）。
        *   支持蓝牙连接主流的智能血压计，一键同步数据，降低手动输入门槛。
        *   标签功能：可为每次测量添加标签，如“清晨空腹”、“运动后”、“服药后”、“感觉不适”等，方便回顾。
    *   **用药记录：**
        *   设置用药计划：药品名称、剂量、服用时间（如早/中/晚）。
        *   每日用药打卡：用户在服药后点击“已服用”，系统自动记录。
        *   支持临时用药记录。
    *   **生活方式记录（可选，简化）：**
        *   简单的体重、运动、饮食（如“口味偏咸”）记录，作为血压变化的辅助参考。

2.  **数据可视化与分析**
    *   **趋势图表：**
        *   将血压和心率数据以线形图展示，可按周、月、季度查看趋势。
        *   在图表上用不同颜色或标记清晰标出“正常”、“偏高”、“危险”等范围。
        *   图表可与用药记录关联，直观展示用药对血压控制的效果。
    *   **数据报告：**
        *   自动生成周报和月报，总结平均血压、最高/最低值、达标率、用药依从性等关键指标。
        *   报告中应包含简单的文字解读和健康建议，例如“本周血压控制平稳，请继续保持”或“本周有3次血压严重超标，建议咨询医生”。

3.  **智能提醒**
    *   **用药提醒：** 根据用户设定的用药计划，在指定时间推送通知，提醒用户服药。
    *   **测量提醒：** 提醒用户在关键时间点（如清晨、睡前）测量血压，确保数据规律性。

4.  **数据分享 (关键功能)**
    *   **生成图片分享：**
        *   将核心的血压趋势图、数据统计或单次详细记录生成一张清晰、美观的图片。
        *   图片上应包含用户昵称、时间范围和关键数据摘要。
        *   用户可直接保存图片到手机相册，或通过微信、短信等方式发送给任何人。
    *   **生成网页链接分享 (H5页面)：**
        *   用户选择要分享的时间段（如近一周、近一月）。
        *   App生成一个加密的、有时效性（如24小时或72小时有效）的网页链接。
        *   医生或家人在任何设备（手机、电脑）上打开链接，即可看到一个交互式的健康报告页面，内容比图片更丰富，可以切换图表、查看详细记录。
        *   这是最灵活、最专业的方式。
    *   **微信小程序卡片分享：**
        *   如果App以小程序形式开发，可以生成小程序卡片，直接分享给医生或微信群。
        *   医生点击卡片即可在微信内快速查看数据，体验流畅。

#### 3. UI/UX 设计原则

*   **简洁至上：** 界面干净，避免任何不必要的装饰和复杂操作。
*   **大字体、高对比度：** 充分考虑中老年用户视力不佳的可能，确保所有文字清晰易读。
*   **操作直观：** 核心功能（如“记录血压”、“分享数据”）应放在最显眼的位置，使用图标加文字说明。
*   **正向激励：** 当用户坚持记录或血压控制良好时，给予“小红花”、“点赞”等积极反馈，增加用户粘性。

### **第二部分：开发计划**

这是一个敏捷开发的迭代计划，旨在快速推出核心功能并根据用户反馈持续优化。

【个人开发者排期】
- V1.0（核心MVP，4-6周）：手动记录、趋势图（周/月）、图片分享、基础分享H5（限时链接）。
- V2.0（智能增强，3-4周）：拍照OCR识别、用药/测量提醒、周报/月报生成与分享。
- V3.0（扩展功能，4-6周）：蓝牙血压计同步、医生端H5查看与筛选。

#### **第一阶段：核心功能开发 (1-2个月)**

*   **目标：** 完成MVP（最小可行产品），满足最核心的记录和分享需求。
*   **开发形式：** 建议优先开发**微信小程序**。
    *   **优势：** 无需安装、依托微信生态易于分享和传播、开发成本相对较低、跨平台（iOS和Android通用）。
*   **任务分解：**
    *   **后端开发：**
        *   用户账户系统（微信授权登录）。
        *   数据库设计（用户表、血压记录表、用药计划表等）。
        *   数据存储和读取的API接口。
        *   数据分享链接生成的服务。
    *   **前端开发 (小程序)：**
        *   用户登录与授权页面。
        *   血压/用药手动录入界面。
        *   数据历史列表页面。
        *   血压趋势图表页面（使用ECharts等图表库）。
        *   生成分享图片和分享链接的功能界面。
*   **技术栈建议（个人开发者）：**
    *   小程序：微信小程序 + 微信云开发（云函数/云数据库/云存储）。
    *   图表：ECharts。
    *   OCR：腾讯云通用文字识别或微信OCR能力（按量计费）。
    *   分享：云函数生成带时效的一次性Token链接（H5）。
    *   通知：微信订阅消息（用药/测量提醒）。

#### **第二阶段：功能优化与扩展 (第3-4个月)**

*   **目标：** 优化体验，增加智能化功能。
*   **任务分解：**
    *   **后端：**
        *   开发数据报告生成逻辑。
        *   开发智能提醒的推送服务。
        *   集成第三方OCR服务API。
    *   **前端：**
        *   开发自动生成周报/月报的页面。
        *   接入推送通知，实现用药和测量提醒。
        *   开发拍照、上传及OCR结果确认界面。
        *   优化图表交互体验。
    *   **硬件接入（调研与开发）：**
        *   研究主流蓝牙血压计的SDK（软件开发工具包）。
        *   在小程序中实现蓝牙连接和数据同步功能。

#### **第三阶段：多平台扩展与生态建设 (第5-6个月及以后)**

*   **目标：** 覆盖更多用户，建立品牌。
*   **任务分解：**
    *   **App开发：** 如果小程序用户量巨大且反馈需要更强大的功能（如离线使用），可以考虑开发独立的Android和iOS App。
    *   **医生端H5查看页：** 开发一个简单的H5查看页面，合作医生可通过患者分享的链接或昵称筛选查看其血压数据，不设计复杂的医生账号体系，后续如有需要再逐步扩展。
    *   **内容运营：** 在应用内增加高血压健康知识、饮食建议等文章或短视频，提升用户留存。

### **数据安全与合规**

- 数据最小化：仅收集必要健康数据，不采集身份类敏感信息。
- 存储安全：云数据库按用户隔离；敏感字段（昵称、备注）脱敏/加密存储。
- 传输安全：全程HTTPS；小程序直连微信云开发，避免中转泄露。
- 分享安全：H5使用一次性Token + 有效期（如24–72小时）；可撤销；仅展示所选时间段数据。
- 用户控制：支持数据导出与删除；提供清晰的隐私政策与用户协议。
- 合规提示：不提供诊断与治疗结论，仅作健康管理与记录工具。

### **第三部分：发布与推广计划**

#### 1. 预发布阶段 (开发完成后)

*   **内部测试：** 邀请公司员工和朋友进行全面测试，修复主要Bug。
*   **种子用户邀请：** 邀请10-20名真实的高血压患者或其家人作为首批种子用户，收集他们在使用过程中最真实的反馈，并快速迭代修改。可以去社区、医院或线上健康社群寻找。

#### 2. 正式发布阶段 (MVP版本上线)

*   **应用市场/平台上线：**
    *   **微信小程序：** 提交到微信平台审核，通过后即可发布。这是最快的方式。
    *   **App Store / Android市场：** 如果开发了App，需要准备相关资料提交审核。
*   **初期推广：**
    *   **线上推广：**
        *   在知乎、小红书、抖音等平台，以“如何帮助爸妈管理血压”、“高血压患者必备神器”等为主题进行内容营销。
        *   建立用户微信群，沉淀核心用户，听取反馈，并让他们帮助传播。
    *   **线下合作：**
        *   与社区卫生服务中心、体检中心或药店合作，向他们推荐这款免费工具，由他们推荐给患者使用。
        *   与一些关心老年健康的公众号或KOL（关键意见领袖）合作进行推广。

#### 3. 长期运营阶段

*   **持续迭代：** 根据用户数据和反馈，不断优化产品功能和体验。
*   **数据驱动：** 分析用户行为数据，了解哪些功能最受欢迎，哪些环节流失率高，并针对性改进。
*   **监控告警：** 接入微信云监控或Sentry Mini Program，记录异常与性能指标，关键接口设告警。
*   **品牌建设：** 组织线上健康讲座，邀请医生入驻答疑，将“心安血压”打造成一个可靠、专业的健康管理品牌。
