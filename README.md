# BBFlow - 高血压健康管理小程序

## 📚 项目结构说明
详细的项目结构与配置文件说明，请参考 [PROJECT_STRUCTURE.md](./PROJECT_STRUCTURE.md)。

## 简介
BBFlow 是一个高血压健康管理小程序，旨在帮助用户更好地管理自己的血压数据，提供健康建议和提醒服务。通过记录每日血压值，用户可以了解自己的血压趋势，及时发现异常情况，并获得专业的健康指导。

## 功能
- 记录每日血压值
- 查看血压趋势图
- 获取健康建议
- 提醒服务

## 使用方法
1. 下载并安装 BBFlow 小程序
2. 打开小程序，登录您的账户
3. 开始记录每日血压值
4. 查看血压趋势图，获取健康建议

## 注意事项
- 请确保血压计的准确性
- 请在安静、放松的状态下测量血压
- 请避免在运动、进食后立即测量血压
